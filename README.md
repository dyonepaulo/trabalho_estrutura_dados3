EXU GAMES -

Trabalho de Estrutura de Dados

Projeto desenvolvido como trabalho acadêmico da disciplina de Estrutura de Dados, utilizando a linguagem C e a biblioteca gráfica Raylib.

O projeto consiste em um jogo de cartas para dois jogadores,

desenvolvido com o objetivo de

aplicar, na prática, conceitos de

estruturas de dados, alocação

dinâmica de memória e programação

em C.

É necessário ter a biblioteca Raylib instalada.

Compilação: gcc bibliotecas/funcoes.c bibliotecas/dados.c -o main -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
